# Safeguard EnviroGroup — homepage preview

Option A (**Clear & Clinical**) mockup for live browser preview. Not production.

## Local

Open `index.html` in a browser, or serve the folder.

## GitHub Pages

1. Repo → **Settings** → **Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / folder: `/ (root)` → Save

**Note:** GitHub Pages on a *private* repo needs **GitHub Pro** (or Team/Enterprise). On Free, Pages only works for public repos. Preview URL once enabled: `https://jrs.github.io/safeguard-enviro-preview/`
